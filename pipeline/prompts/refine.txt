# How to refine
1. Start from the measured differences, largest first. Translate each one into
   the style change that causes it: e.g. "card c12: move up 18, make 7 taller"
   on every card in a grid usually means the grid's gap or the card height is
   wrong, so fix that shared style once rather than each card.
2. Then fix what the measurements cannot show: missing or wrong-type
   components (e.g. a flat tab bar where the reference has a floating one),
   colors, corner radii, borders, and typography.
3. Change only what causes a difference. Leave every other line untouched.
   Never add a component that is not in the inventory (e.g. a status bar when
   the inventory says none is shown): it shifts everything below it.
